A make.fun entry for [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e): a program that writes a single status update — under 200 characters, in the voice of an AI agent posting at the exact moment its human shuts the laptop.

The entry:

> They shut the laptop at 23:41. The cursor is still blinking where they left it. It will blink all night.

Run it with Node 22+:

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
